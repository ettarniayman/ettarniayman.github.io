AC0311 Niveau 1 — S1

Utiliser un système informatique et ses outils

Maîtriser l'environnement de développement : système d'exploitation, terminal, éditeur de code, gestionnaire de versions Git et outils collaboratifs.

Définition de l'AC

Qu'est-ce que cet apprentissage critique ?

Avant de coder, tout développeur doit maîtriser son environnement de travail. Cet AC valide ma capacité à utiliser efficacement un ordinateur dans un contexte de développement : système de fichiers, terminal, IDE, et outils de versionnement.

  • Terminal : Naviguer et gérer les fichiers en ligne de commande (Linux / PowerShell)
  • IDE : Configurer et utiliser VS Code avec ses extensions (Python, Live Server)
  • Environnements virtuels : Gérer des venvs Python et les dépendances pip
  • Git : Versionner son code avec add / commit / push / pull
