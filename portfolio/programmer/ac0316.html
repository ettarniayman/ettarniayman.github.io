AC0316 Niveau 1 — S1/S2

S'intégrer dans un environnement propice au développement et au travail collaboratif

Utiliser les outils de versionnement Git et les plateformes GitHub / GitLab pour travailler en équipe, gérer l'historique du code et publier un projet.

Définition de l'AC

Qu'est-ce que cet apprentissage critique ?

Cet apprentissage valide ma capacité à travailler dans un environnement collaboratif de développement. Il s'agit de maîtriser Git, de publier des projets sur GitHub et GitLab, et de collaborer efficacement sur un dépôt partagé.

  • Git : Workflow complet — branches, merge, résolution de conflits, historique
  • GitHub Pages : Déploiement continu d'un site statique depuis un dépôt Git
  • GitLab : Utilisation du GitLab de l'IUT Artois pour les projets de cours
  • Travail en binôme : Collaboration sur un dépôt partagé (SAÉ15 avec N. El Bouziani)
Mise en pratique
SAÉ14 — Portfolio versionné sur GitHub

Développement itératif de ce portfolio avec commits réguliers, gestion de l'historique et déploiement automatique GitHub Pages à chaque push sur main.

SAÉ15 — Travail collaboratif sur GitLab IUT

Projet de supervision réseau développé en binôme sur le GitLab de l'IUT Artois — branches de fonctionnalités, merge requests et revue de code.

Réflexion personnelle
✅
Points maîtrisés

Git add/commit/push/pull, création de branches, déploiement GitHub Pages, utilisation du GitLab IUT.

📈
Points à améliorer

Git rebase interactif, squash de commits, gestion propre des conflits de merge complexes.

💡
Difficultés rencontrées

Résoudre les conflits de merge lors du travail en parallèle sur les mêmes fichiers — nécessite une bonne organisation des branches.

🎯
Objectifs futurs

Mettre en place un pipeline CI/CD GitLab pour automatiser les tests et déploiements des projets.
