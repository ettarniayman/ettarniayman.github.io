AC0314 Niveau 1 — S2

Connaître l'architecture d'un site Web

Comprendre et utiliser les technologies web fondamentales (HTML, CSS, JavaScript) et le développement backend avec Python/Flask pour créer des interfaces fonctionnelles.

Définition de l'AC

Qu'est-ce que cet apprentissage critique ?

Cet apprentissage valide ma capacité à comprendre l'architecture client-serveur d'un site web et à développer des pages statiques et dynamiques. Il s'agit de maîtriser HTML/CSS côté client et Python/Flask côté serveur.

  • HTML/CSS : Structure sémantique, mise en page responsive avec Bootstrap
  • Python/Flask : Routage, templates Jinja2, factorisation des vues
  • Architecture MVC : Séparation modèle / vue / contrôleur dans une application Flask
  • Déploiement : Hébergement d'un site statique sur GitHub Pages
Mise en pratique
R2.09 — TP3 Flask : Factorisation et vues

Développement d'une application Flask avec factorisation des routes et templates Jinja2 — organisation en blueprints et séparation des responsabilités.

SAÉ14 — Ce portfolio (HTML/CSS/Bootstrap)

Création d'un site entièrement en HTML/CSS/Bootstrap déployé sur GitHub Pages — architecture multi-pages, navigation responsive, thème sombre personnalisé.

Réflexion personnelle
✅
Points maîtrisés

HTML sémantique, CSS responsive, Bootstrap, structure d'une application Flask, templates Jinja2.

📈
Points à améliorer

JavaScript avancé (fetch API, async/await), sécurisation des formulaires web (CSRF, validation serveur).

💡
Difficultés rencontrées

Comprendre le routing Flask et la gestion des contextes dans les templates Jinja2 — l'organisation en blueprints demande une bonne architecture initiale.

🎯
Objectifs futurs

Développer une application Flask complète avec authentification, base de données et API REST.
