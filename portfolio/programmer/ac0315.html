AC0315 Niveau 1 — S2

Choisir les mécanismes de gestion de données adaptés

Sélectionner et utiliser les structures de données et systèmes de stockage appropriés (fichiers, bases de données SQL) pour le développement d'outils réseau.

Définition de l'AC

Qu'est-ce que cet apprentissage critique ?

Cet apprentissage valide ma capacité à choisir le bon mécanisme de persistance des données selon le contexte applicatif. Il s'agit de maîtriser le SQL, les bases de données relationnelles et les formats d'échange courants (JSON, CSV).

  • SQL : Création de tables, requêtes SELECT/INSERT/UPDATE/DELETE, jointures
  • PostgreSQL : Déploiement d'une base de données relationnelle, gestion des utilisateurs
  • Formats d'échange : JSON, CSV — parsing et génération en Python
  • ORM : Utilisation de SQLAlchemy avec Flask pour interagir avec la base
Mise en pratique
R2.09 — TP1 Création de base de données SQL

Conception et implémentation d'une base de données PostgreSQL : modélisation MCD/MLD, création de tables, insertion de données et requêtes SQL complexes.

SAE15 — Stockage de données réseau en JSON/CSV

Développement de scripts Python pour collecter des données réseau (résultats de ping, inventaire ARP) et les persister en format JSON et CSV pour analyse ultérieure.

Réflexion personnelle
✅
Points maîtrisés

Modélisation relationnelle, requêtes SQL de base, manipulation de JSON/CSV en Python, création de bases PostgreSQL.

📈
Points à améliorer

Requêtes avancées (sous-requêtes, fenêtres analytiques) et utilisation d'un ORM complet avec Flask-SQLAlchemy.

💡
Difficultés rencontrées

Choisir la bonne normalisation de la base (1NF, 2NF, 3NF) pour éviter les redondances sans sur-complexifier le schéma.

🎯
Objectifs futurs

Intégrer une base de données dans une application Flask complète avec API REST et gestion des migrations.
