AC0116 Semestre 1

Installer un poste client

Préparer, installer et configurer un poste de travail (système d'exploitation, pilotes, logiciels métier, connexion réseau) prêt à être intégré dans un parc informatique.

Définition de l'AC

Pourquoi cet apprentissage critique ?

L'installation et la configuration d'un poste client est l'une des tâches les plus fréquentes du technicien support. Au-delà de simplement installer un OS, il s'agit de préparer un poste prêt à l'emploi, sécurisé, connecté au réseau de l'entreprise et conforme aux politiques de sécurité.

  • Installation OS : Windows 10/11, Ubuntu, Debian — partitionnement, BIOS/UEFI
  • Configuration réseau : IP statique ou DHCP, DNS, passerelle
  • Intégration : jonction à un domaine Active Directory, mappage de lecteurs réseau
  • Sécurité : mises à jour Windows Update / apt, antivirus, pare-feu local
  • Virtualisation : VirtualBox / VMware pour tester des configurations
Mise en pratique
SAÉ 11 — Mise en service d'un poste

Installation d'une VM Debian en salle réseau : partitionnement LVM, configuration réseau statique, installation des paquets nécessaires (openssh, vim, curl).

TP — Virtualisation avec VirtualBox

Création d'une machine virtuelle Windows 10 en réseau NAT, configuration des interfaces réseau, installation des additions invité.

Étapes clés d'une installation professionnelle :

  1. Vérification du matériel (RAM, disque, compatibilité UEFI)
  2. Installation de l'OS depuis clé USB bootable (Rufus / dd)
  3. Configuration réseau (IP, DNS, gateway)
  4. Mise à jour système et installation des drivers
  5. Installation des logiciels métier
  6. Tests de connectivité et validation
Réflexion personnelle
✅
Points maîtrisés

Installation OS (Windows/Linux), configuration réseau de base, virtualisation sous VirtualBox.

📈
Points à améliorer

Déploiement de masse via MDT/WDS ou Ansible, et intégration complète à Active Directory.

💡
Difficultés rencontrées

Gérer les conflits de drivers sous Windows et configurer correctement le UEFI/SecureBoot.

🎯
Objectifs futurs

Automatiser le déploiement de postes via des scripts PowerShell et des images système préconfigurées.
