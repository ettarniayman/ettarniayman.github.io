AC0114 Semestre 1

Maîtriser les rôles et principes fondamentaux des systèmes d'exploitation

Interagir avec les systèmes d'exploitation (Linux, Windows) pour configurer et administrer les services réseau : gestion des fichiers, des utilisateurs, des processus et des services.

Définition de l'AC

Pourquoi cet apprentissage critique ?

Un administrateur réseau passe l'essentiel de son temps à interagir avec des systèmes d'exploitation, notamment en ligne de commande. Configurer un serveur DHCP, DNS, ou SSH passe nécessairement par la maîtrise du terminal Linux ou de PowerShell sous Windows.

  • Structure du système : arborescence, processus, threads, scheduling
  • Gestion des fichiers : permissions, droits Linux (rwx), commandes de base
  • Services réseau : démarrage/arrêt (systemctl), journaux (journalctl)
  • Administration distante : SSH, transfert de fichiers (SCP, SFTP)
  • Shell scripting : automatisation basique en bash
Mise en pratique
R101 / R201 — Systèmes Linux

Travaux pratiques sous Debian/Ubuntu : navigation dans l'arborescence, gestion des utilisateurs et groupes, configuration réseau avec ip/ifconfig, installation de services.

SAÉ 13 — Automatisation d'une infrastructure

Déploiement d'un serveur Linux : configuration SSH pour administration à distance, mise en place d'un serveur DHCP et DNS, et scripts d'automatisation bash.

Commandes clés utilisées :

$ ls -la /etc/network/ # Explorer la config réseau
$ sudo systemctl status ssh # État du service SSH
$ sudo systemctl enable dhcpd # Démarrage automatique DHCP
$ chmod 600 ~/.ssh/authorized_keys # Sécuriser les clés SSH
$ ip addr show # Afficher les interfaces
$ journalctl -u networking # Journaux du service réseau
