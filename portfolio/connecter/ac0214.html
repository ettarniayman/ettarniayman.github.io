AC0214 Niveau 1 — S1

Connecter les systèmes de ToIP

Déployer et configurer une solution de téléphonie sur IP : serveur IPBX, softphones SIP, plan de numérotation, analyse des flux RTP/SIP avec Wireshark.

Définition de l'AC

Qu'est-ce que cet apprentissage critique ?

Cet apprentissage valide ma capacité à déployer une infrastructure de téléphonie sur IP (ToIP). Il s'agit de comprendre les protocoles SIP et RTP, de configurer un serveur IPBX, de créer des comptes téléphoniques et d'analyser les échanges dans Wireshark.

  • Protocole SIP : Comprendre les échanges INVITE, 200 OK, BYE, ACK
  • Serveur IPBX : Configuration Asterisk ou 3CX avec plan de numérotation
  • Softphones SIP : Création de comptes et tests d'appels avec Zoiper
  • Wireshark : Analyse des échanges SIP et des flux RTP d'un appel complet
Mise en pratique
R102 — Étude des protocoles SIP et RTP

Étude des protocoles SIP (Session Initiation Protocol) et RTP (Real-time Transport Protocol) — échanges de messages SIP capturés et analysés avec Wireshark.

R204 — Configuration d'un server Cisco et Asterisk et tests d'appels

Configuration d'un IPBX (Asterisk ou Cisco) avec création de comptes SIP et tests d'appels inter-postes — analyse des flux dans Wireshark pour vérifier le bon déroulement des sessions.

Réflexion personnelle
✅
Points maîtrisés

Compréhension du protocole SIP (INVITE, 200 OK, BYE), configuration d'un compte SIP sur un softphone, analyse d'un appel dans Wireshark.

📈
Points à améliorer

Configuration avancée d'un IPBX (IVR, groupes d'appels, messagerie vocale, interconnexion multi-sites).

💡
Difficultés rencontrées

Résoudre les problèmes de traversée NAT avec le protocole SIP — les adresses privées posent problème pour les appels externes.

🎯
Objectifs futurs

Déployer une solution ToIP complète pour une PME avec QoS, chiffrement SRTP et plan de numérotation avancé.
